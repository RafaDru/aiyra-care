# Feature cards — AiyraCare

Uma **feature card** descreve **uma capacidade de produto** (não um arquivo de código).

## Convenção

| Campo | Regra |
|-------|--------|
| **Arquivo** | `docs/features/<roadmap-item-id>.md` |
| **ID** | Igual ao `items[].id` ou `epics[].id` em `roadmap.json` |
| **index.json** | Obrigatório registrar toda card nova |
