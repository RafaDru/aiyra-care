# Investigação — incidente 96a2e898 / defeito 0e672818

**Fingerprint:** `036967be53b57d23` → `ui|ui_boundary|error` (feature `ui` via `reportUiBoundaryError`, não rota).

**Rota reportada:** `/` (Dashboard dentro de `AppLayout`).

**Apps:** Web.

## Hipótese

Após #49, `Dashboard` chama `useActiveCareCircle()`, que lança se não houver `ActiveCareCircleProvider`. Em `AppLayout`, o provider só era renderizado quando `configured && user`, enquanto o `Outlet` (Dashboard) sempre monta para rotas autenticadas — incluindo modo legado `!configured` (`RequireAuth` libera `Outlet` sem Supabase) e qualquer frame em que o layout renderize sem `user` alinhado ao hook.

Erro React genérico `Error` → borda `AppErrorBoundary` → telemetria recorrente na home em integration.

## Correção

Montar `ActiveCareCircleProvider` sempre em `AppLayout` (o contexto já trata `!configured || !user` em `refreshCircles`). Manter `CareCircleGlobalSelector` condicionado a `configured && user`.

**Arquivo:** `packages/web/src/components/layout/AppLayout.tsx`
